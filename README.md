# stevenecreech.github.io

Personal website of Steven Creech, built with Jekyll and hosted on GitHub Pages.

- Layout: `_layouts/default.html`, styles in `css/main.css`.
- Each tab is a folder with an `index.html` (e.g. `research/`, `lean/`, `trace-formula/`).
- Art posts live in `_posts/` with `categories: art` and are published under `/art/<title>/`.
